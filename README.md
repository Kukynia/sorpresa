# 🌻 Sorpresa Romántica: "Girasol de Amor" 💖

Una experiencia interactiva web, tierna y cuidada al milímetro para dedicarle a tu novia por WhatsApp y abrir desde su iPhone.

---

## ✨ ¿Cómo funciona?
1. Al entrar se encuentra con una hermosa maceta y el título **“Te amo porque...”**.
2. Abajo tiene un botón llamativo y dulce: **“¿por qué? 🥰”**.
3. Con cada toque, el tallo verde va creciendo orgánicamente y brotan hojas mientras aparecen tus 5 frases:
   - 🌿 **Paso 1:** *"Sos incondicional❤️"*
   - 🌿 **Paso 2:** *"🥰Sos incansable y muy fuerte💪"*
   - 🌿 **Paso 3:** *"❤️Siempre me sanás😊"*
   - 🌿 **Paso 4:** *"🥰Donde vos estés, todo brilla✨"*
   - 🌻 **Paso 5 (Gran Final):** Brota y se abre un majestuoso **Girasol**, explotan chispas y confeti dorado, suena una melodía de campanillas romántica y aparece:
     - *"🌻Hacés que la vida sea más hermosa🌻"*
     - La nota final: *"¡Por esto y un millón de razones más, te elijo siempre! 💖"*
4. Al tocar el girasol ya abierto, ¡vuelven a salir destellos mágicos!

## 🚀 Cómo publicarlo en GitHub Pages (Paso a Paso)

Para tener el enlace listo para WhatsApp (`https://tu-usuario.github.io/sorpresa`):

### Paso 1: Crear el repositorio en GitHub
1. Entra a [GitHub.com](https://github.com) e inicia sesión.
2. Haz clic en el botón verde **"New"** para crear un nuevo repositorio.
3. Ponle de nombre, por ejemplo: `sorpresa` o `para-vos` (asegúrate de que sea **Público**).
4. Haz clic en **"Create repository"**.

### Paso 2: Subir los archivos
En tu terminal o desde la misma página de GitHub:
- Si usas la página web de GitHub: arrastra y suelta los archivos `index.html` y `sorpresa.html` en el área de **"uploading an existing file"** y haz commit.
- O por consola desde esta carpeta:
  ```bash
  git init
  git add .
  git commit -m "Mi sorpresa para ella ❤️"
  git branch -M main
  git remote add origin https://github.com/TU-USUARIO/NOMBRE-DEL-REPO.git
  git push -u origin main
  ```

### Paso 3: Activar GitHub Pages
1. Dentro de tu repositorio en GitHub, ve a la pestaña **Settings** (Configuración) arriba a la derecha.
2. En el menú lateral izquierdo, haz clic en **Pages**.
3. En la sección **Branch**, selecciona `main` (o `master`) y la carpeta `/ (root)`.
4. Haz clic en **Save** (Guardar).
5. ¡Listo! En unos segundos GitHub te dará tu enlace verde arriba, que se verá así:
   👉 `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`

Ese es el enlace que puedes enviarle por WhatsApp junto con un mensajito tierno. 🥰
